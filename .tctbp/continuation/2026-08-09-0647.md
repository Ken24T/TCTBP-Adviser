## Mistakes & Gotchas

- **Dev-server restarts can look like app failures**: editing server files triggers a Vite auto-restart; a failed mid-edit restart left the API down ~80s and the user's checkpoint clicks returned `ERR_CONNECTION_REFUSED` → looked like an infinite loop. When a user reports "it keeps failing", check the dev-server terminal for restart failures before assuming a repo bug. (Server 500s are now logged too.)
- **Don't gate the incompatible+dirty checkpoint sequence on advertised workflows**: an incompatible contract advertises **zero** workflows, so `workflowAvailable('checkpoint')` is false — the guard silently fell back to the old stop. Removed it (checkpoint runs regardless of compatibility).
- **"Working tree has local changes" after an apply is the apply→checkpoint handoff, not a failure.** Now framed as amber "Commit before continuing" and paired with "Applied N change(s)…" feedback that survives the plan refresh.
- **A reconciled repo needs `.tctbp/source.json` to reach 'Current'** — without it, `sourceAlignment` stays `unknown` and disposition stays `review-required` forever. Fixed by writing the manifest on apply + the Record-alignment step.
- **`renderToStaticMarkup` HTML-escapes apostrophes** (`&#x27;`) — test assertions must avoid apostrophes or match the escaped form.
- **`multi_replace_string_in_file` needs unique oldStrings** — identical prop blocks in tests must be disambiguated with surrounding context.
- Jasper (OpenAI-compatible) intermittently returns "reasoning content but no final answer" → retry "Ask Jasper" usually succeeds.
